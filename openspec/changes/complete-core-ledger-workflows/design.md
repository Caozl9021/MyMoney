# 实施决定

1. D6用可单测的轮询节拍策略区分有效抓取/空转/息屏，避免死标志；默认1200ms、空闲至少3000ms、息屏30000ms。
2. F5采集结果携带items+truncated，保留原collect接口供兼容；无障碍/root/OCR贯通，成功及skip均显示截断。
3. 退款引入REFUND（正金额），独立展示，不再算收入；收支卡显示原支出、退款及结余（收入-支出+退款），不猜测关联原账，不修改历史INCOME记录。Room type为字符串无需schema迁移；备份/队列/确认/分类/显示全链路兼容。现有iCost仅支出收入转账三词、正金额模板，遇退款明确阻止导出并显示原因，绝不伪装收入或静默丢行；记录该格式限制。
4. 编辑保留id/createdAt/source等元数据，仅更新用户编辑字段并刷新fingerprint；新建允许支出/收入/转账/退款、金额/商户/分类/账户/备注；非法金额不能保存，关闭不落库。应用内使用Dialog承载共用ConfirmSheet并处理返回和键盘；不要让dock盖过编辑卡。
5. 删除通过可撤销的临时隐藏/延时提交或已删可恢复机制，5秒内可撤销，多条操作不能覆盖丢失；离页/重建不导致永久意外丢账。编辑与新增提供明确入口及保存结果，DAO写操作可靠。

边界：不扩展低安卓支持，不做外部App自动操作；不改采集权限。主代理执行最终集成测试及模拟器。Git元信息不可用时备份源码并记录摘要。
