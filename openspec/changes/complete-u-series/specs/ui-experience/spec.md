# 需求与场景
## 状态反馈 U3
确认卡金额出现时克制的短暂光晕；统计比例连续变化；开启开关有细微强调描边，无持续闪烁。降低动效时不执行过渡。
## 连续动效 U4
设置子页有方向一致的进退过渡并保留页状态；确认卡抓手跟随手指，距离120dp或向下速度1000px/s关闭，反向/不足回弹，速度影响回弹；明细到编辑金额有连续过渡（跨窗口不可行时使用同窗口编辑层），不得破坏保存/取消/系统返回；系统移除动画或应用降低动效均停止非必要过渡，含dock。
## 鲁棒性 U5
外观支持跟随/浅/深、标准/大/特大、降低动效；保留当前固定轻玻璃，不恢复旧强度滑块。普通文本尊重大字号，金额单独限制增长避免溢出，不全局压低系统字号。固定行/按钮可撑高，图标按钮有名称与至少48dp点击区；内容最大560dp居中，dock在常规字号保持当前尺寸，大字号可适配。
## 主题图标 U6
Android13+有独立单色遮罩，沿用当前图形轮廓和留白，旧彩色图标不变；系统accent已有则保留，不改变分类稳定色。
## 首页 U7/U8
待确认在概览前；仅概览为主卡；最近行分类/子类+时间，账户在详情。首次引导按所选ROOT/ACCESSIBILITY展示权限与识别步骤，实际状态驱动完成，全部完成自动隐藏，可手动新增账单，已有正常用户无常驻权限快捷卡。
## 系统入口 U9
长按记一笔、桌面本月支出+记一笔小组件均打开合法手动编辑器（空金额不能直接保存）；磁贴反映所选模式+总开关并通过CaptureModeManager统一切换，未选模式引导选择，不直接调用su/旁路权限。widget显示真实支出，退款不算原支出，账单变化/切月可更新，PendingIntent不可变且不串用。无需新依赖，组件只暴露必要入口。
## 一致性 U10
概览可翻月且标明月份与当前统计一致；左滑删除背景随进度揭示，保留独立撤销；深色底0B0B0C或当前已等效值；chip/list选中统一语义色，dock仍中性灰。
## 验证约束
194原单测无回归；为时段/阈值/入口与合计等纯逻辑添加必要测试；测试后debug构建，在API35模拟器检查浅深色、大字号2.0、减少动画、入口/编辑/取消、磁贴/widget注册与布局。未实际验证的设备能力显式记录，不以代码存在宣称验收。无release/dist，用户验收前状态待验收。

## 用户授权发布构建
产物应为com.example.autobook / 0.6.7 / 26；release签名有效且证书与旧release一致，可覆盖旧签名安装。debug和release均构建，旧dist不覆盖，保留测试和产物SHA256。打包不等同用户验收，未实测能力仍需披露。
