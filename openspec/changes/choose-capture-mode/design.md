# 决策

新增明确CaptureMode（ROOT/ACCESSIBILITY）与独立识别总开关；选择持久化SharedPreferences，不将权限暂不可用自动切成另一模式。首次未选择显示覆盖dock的选择界面，可选择模式后进入App，设置提供同一选择入口。新安装选择后启用识别；切换模式保留总开关，暂停识别不清空选择。

已有root_mode=true迁移为ROOT；非Root已有无障碍配置可沿用ACCESSIBILITY，无法可靠确定则让用户选择，不擅自选Root或请求su。旧rootMode API按新模式兼容，备份恢复不静默覆盖已有明确模式选择；保留老备份兼容。

CaptureModeManager提供可观察状态以及一致起停：ROOT仅Root采集；ACCESSIBILITY仅无障碍采集；系统仍绑定无障碍时Root模式忽略事件（不要求用户关闭）。App启动/开机/服务重建/总开关/模式切换均检查资格，停止不取消用户模式。无障碍模式不自动探测Root或调用su/OCR root截图；OCR按Root模式展示可用性。

权限及状态提示模式化：Root展示授权/监听状态+悬浮窗/通知，无障碍展示服务状态+悬浮窗/通知；Root授权检测仅Root相关明确操作或Root服务启动，不进入普通设置就探测Root。首次选择本身不要求权限均已授予，以免无Root设备或拒绝授权被困死；模式继续保存并显示下一步。

主代理核查UI和状态一致性，模拟器验证首次/重开/切换/拒绝Root。不清除原用户数据，首次场景用独立测试安装或可恢复的模式键基线验证，记录测试后模式。固定dock及账本功能不变。
