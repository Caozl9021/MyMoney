# Floating dock

## ADDED Requirements

### Requirement: 胶囊视觉与阴影稳定
Dock MUST 在 Android 13+ 保持居中胶囊、等距四入口、完整圆润外投影，无全宽遮罩及内侧黑斑；选中块 MUST 为中性色。固定玻璃折射参数保持现有设计。

#### Scenario: 浅深主题显示
- WHEN 用户显示首页及设置并切换浅深主题
- THEN 标签清楚、选中块可辨、阴影不呈矩形截断，最后一项可滚到 dock 上方。

### Requirement: 切换状态连续
Dock MUST 声明 Tab 角色及选中语义，切换反馈克制；各 Tab MUST 保留可保存状态。

#### Scenario: 来回切页
- WHEN 用户滚动明细、选取统计月份或进入设置子页，再切换其他 Tab 后返回
- THEN 原位置、月份及子页恢复；重复点击当前 Tab 不重复触发切换触感。

#### Scenario: Activity 重建
- WHEN 系统重建 Activity
- THEN 当前 Tab 及可保存的页面状态恢复。

### Requirement: 可核查交付
交付 MUST 包含单测与构建结果，并明确模拟器实测范围、未覆盖情况；用户明确验收前 MUST 保持待验收。

### Requirement: 选中色块更贴近外缘
色块 MUST 在原中心向四周扩大3dp，图标、点击区域及dock尺寸 MUST 保持原位。

#### Scenario: 首末Tab选中
- WHEN 用户选择首页或设置
- THEN 色块到dock对应外缘约3dp，上下留白约3dp，无越界。


## 2026-10-22 视频参考优化（0.6.6，待验收）

### Requirement: 参考视频的轻透材质
Dock MUST 使用更弱的折射/色散与柔和投影、细边缘高光，浅深主题保持可读；此前固定玻璃参数要求由此替代。
#### Scenario: 背景滚动
- WHEN 内容经过dock底部
- THEN 内容有适度柔化与边缘折射，不出现强烈彩虹拉扯，高光不遮盖图标。
### Requirement: 连续滑块动效
选中块 MUST 在Tab间连续位移，移动时允许轻微形变且收稳，文字图标保持稳定；快速切换不跳变。
#### Scenario: 连点和反向
- WHEN 用户快速点击不同入口后反向
- THEN 动画从当前位置接续，落位对应实际选中Tab，不改变页面保存策略。
#### Scenario: 水平拖动（若提供）
- WHEN 用户拖动后松手或取消
- THEN 松手只提交最近合法入口一次，取消回原选择，移动不越界且不反复触感。


### 用户追加：中性近白底色与通透性
参考 `截图/351f5761-a46d-4af3-bd8c-8418dabcdd26.jpg` 左侧KernelSU底色；用户明确现有底色叠加玻璃显灰不通透。浅色pageBg改中性近白（截图均匀区约#F7F7F7，采样为准），白色卡片保留层次；dock减少灰色着色/阴影及色散，不能仅加白色蒙层。深色维持适当对比，不照搬浅色近白。纳入T10与T12验收。
