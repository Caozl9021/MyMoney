# 方案

保持胶囊 68dp 高、底距导航栏 16dp、标准手机左右约 50dp 的视觉比例。阴影采用独立层并确保模糊边缘有足够绘制空间，禁止不配对 Canvas restore、禁止 CLEAR 影响页面；必要时用预渲染位图避免硬件画布模糊差异。选中块维持中性灰，图标文字和点击区域等距居中；标签适度增大，动画收敛；使用 selectable/Tab 语义。以 SaveableStateHolder 按 Tab 保存滚动、统计月份和设置子页，Activity 恢复所选 Tab；多 ComposeView 须有稳定 ID。固定折射参数，避免凭旧文档恢复不存在的滑块。

验证优先使用现有安卓虚拟设备，不清数据、不卸载已有应用；签名不匹配时保留数据并记录阻碍。CLI 不可用时手工检查 OpenSpec 文件结构与需求任务映射。

实测迭代：黑色空白页下纯透明玻璃难以分辨，深色采用cardBg、alpha0.65的轻微底色，浅色保持原透明值。固定折射/色散/模糊不变。

选中色块微调：保留6dp内容网格，以色块向四周外扩3dp实现，宽高各增加6dp、中心与原位置不变，首末色块到dock外缘约3dp。


## 2026-10-22 视频参考优化（0.6.6，待验收）

在既有独立采样、玻璃、阴影、图标层上调整：明显减小折射高度/偏移/色散，模糊适中，浅深主题低饱和中性薄底色；独立非交互边缘层画细微上下明暗高光，阴影保持缓存软件位图与CLEAR隔离，改轻柔双层投影。选中块用连续位置弹簧动画，位移期间轻微横向拉伸/纵向压缩，落位收稳，快速连续点击从当前位置接续而非跳回。支持水平拖动预览与松手落最近Tab（若实现则取消恢复原Tab、钳制范围、一次有效选择只反馈一次），点击/无障碍选择保持。API<33共享选中动效与轻量边缘效果。禁止逐帧分配Bitmap或修改无关业务。保留68dp高/左右50dp/底16dp+inset及3dp滑块外缘。

参考 `截图/351f5761-a46d-4af3-bd8c-8418dabcdd26.jpg` 左侧KernelSU底色；用户明确现有底色叠加玻璃显灰不通透。浅色pageBg改中性近白（截图均匀区约#F7F7F7，采样为准），白色卡片保留层次；dock减少灰色着色/阴影及色散，不能仅加白色蒙层。深色维持适当对比，不照搬浅色近白。纳入T10与T12验收。


## 扁长比例模拟器预览（2026-10-22，待验收）
AbSize统一60dp高度与36dp侧距供真假玻璃使用，标签间距3→2dp。维持3dp滑块边缘与中性轻透材质；页面底部留白自动跟随高度。使用已有API35 AVD可见窗口，不清数据，不卸载应用，核签名后覆盖安装debug预览；只在需要首次模式时选ACCESSIBILITY并暂停采集避免权限影响预览。

用户预览追加：仅dock图标文字整体略缩小，选中图标25→23dp，未选中22→21dp，标签12→11sp；保持点击区域、语义及60dp/36dp不变。纳入T13/T14预览验收，业务页面字号不变。
