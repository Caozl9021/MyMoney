## 已有能力与使用入口

- 首页：选中账期摘要、待处理、按自然日倒序日卡；默认当前账期，可翻历史期且日卡同步，保留完整日小计和期内分页。统计右上明细提供全库搜索/组合筛选及逐笔编辑、删除撤销。
- 统计：周/月、收支退款类型、每日趋势/跨月热力图、分类/账户占比；转账不计收支，结余=收入−原支出+退款。
- 资产：概览与资金账户；详情按账期显示非本金转账明细，更多可管理单个账户。设置→资产提供转账/还款、账户管理与归档显示，稳定身份/余额联动与历史导入不重复扣减保持。
- 设置→记账周期：每月1–31日起算，短月取月底并恢复原日；首页/明细/月统计/导出/组件同源，今天与周统计不变。日期选择为同源设置子页，选定后还需保存。
- 设置→导入导出：钱迹XLSX导入、iCost CSV导出、完整备份恢复。钱迹导入支持CNY支出/收入/完整转账；报销、债务、优惠券等未支持行明确跳过。iCost范围含退款或转账时阻止整次CSV导出，完整保留使用JSON备份。
- 自动记账与规则：普通模式可按需使用通知/页面辅助；Root模式使用Root通知及可选LSPosed，银行短信独立开关。通知优先匹配已验证模板，再交给本地规则；通道可用不代表每种交易都能命中。识别后由用户确认保存，关闭弹卡进入待确认。权限、真实交易及LSP效果以实际证据为准。

## 数据与边界

金额按分Long保存；账单、识别历史、账户流水分别保持身份与关联。JSON8含采集元数据、钱迹导入身份/删除标记、账期配置及待确认转入账户；旧备份缺失字段遵循保留语义。系统allowBackup仍关闭。备份恢复与外部分享不是同一操作，发起分享不能证明第三方已入账。

## 构建与安装

当前工作分支：`master`（主线）与 `self`（2026-10-29 新建，用于隔离改动）。`build-all.sh` 按分支命名产物：`dist/AutoBook-<版本>-<分支>-{debug,release}.apk`（master→`-master-`，self→`-self-`），两分支同版本互不覆盖。

```bash
source ~/opt/autobook-env.sh
./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug :app:assembleRelease :app:assembleDebugAndroidTest
# 安装已核验的同签名正式包（按当前分支选择 -master- / -self- 文件名）
adb install -r dist/AutoBook-0.32.0-master-release.apk
```

仅在依赖缓存完整时添加`--offline`。正式签名在仓库外的用户配置中读取，debug与release签名不同；覆盖升级以连续release签名为准，不能用卸载规避签名冲突。

## 识别历史与备份

## 识别历史与备份

成功识别先保存本地历史，再尝试显示确认卡；首页显示待处理数量，首页和明细均保留“识别历史”入口，可筛选全部、待处理、已记账和已忽略。关闭卡片仍待处理；“忽略”保留可回看记录，可在历史中重新确认。已记账历史只读，关联账单删除后不会自动变成可再次入账的草稿。手动记账不产生识别历史。

历史默认永久保留，没有20条淘汰上限；旧待确认队列会迁入历史。仅“清理已忽略记录”在明确确认后删除这些历史，不删除账本。历史保存账单字段及状态，不永久保存整屏原文，不引入服务器或网络服务。

“设置 → 导出 → 备份与恢复”的 JSON2 包含账本、全部历史和处理/分享状态；兼容旧 JSON1，旧格式恢复保留本机历史。合并不重复账单、不把已记账历史降为待处理；覆盖前会说明替换范围并二次确认。升级和覆盖前先导出备份。分享只显示已发起或失败，外部是否导入需在目标应用确认。

身份优先使用完整订单标识哈希，其次页面明确时间，弱标识按连续页面会话区分。没有时间/单号且未观测到页面边界的两笔完全同页交易仍可能无法区分，不能据此承诺完全根治F9。页面未提供的账单时间会标明按识别时间代用，不当作页面交易事实。

## 构建与安装

需要 JDK 17、Android SDK 35；项目使用 Gradle 8.14、AGP 8.7、Kotlin 2.0.21，最低 Android API 26。

```bash
source "$HOME/opt/autobook-env.sh"
cd "$HOME/Projects/AutoBook"
./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

环境脚本适用于当前工作机；其他机器自行设置 JDK/SDK，并调整 `local.properties`。若 Gradle 缓存目录不可写，在加载环境后将 `GRADLE_USER_HOME` 设为可写目录。签名、正式打包与升级说明见 [部署指南](DEPLOYMENT.md)。视觉精修 0.9.0/42 已核对包内版本、与 0.8.2 连续签名及摘要，并同签名覆盖安装真机，待用户验收；下列安装示例指向该待验收包，最终证据见 [本轮验证报告](runs/20261025-135702-visual-refresh/outputs/verification.md)。升级前先备份，使用与已安装版本同签名的包：

```bash
source "$HOME/opt/autobook-env.sh"
adb install -r dist/AutoBook-0.9.1-release.apk
```
