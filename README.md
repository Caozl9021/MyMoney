# AutoBook

Android 本地自动记账 App：采集支付或购物 App 当前页面的文本，按规则识别账单，提供确认卡并保存到本地账本。支持 CSV 导出到 iCost，不复用第三方 App 的代码、资源或私有数据。

当前候选版本为 **0.6.8 / versionCode 27（待用户验收）**。安装包位于 [dist](dist/)；最新验证见 [测试报告](TEST_REPORT.md) 和 [原始验证记录](runs/20261023-092336-brand-jpg-wechat-release/outputs/verification.md)。[plan1.0](docs/PLAN_1.0.md) 是下一轮规划，新增内容尚未实施，不是发布版本。

## 当前能力

- 首次选择 **无障碍**或 **Root** 采集模式，两者互斥；模式选择与识别总开关独立保存。无障碍读取节点；Root 通过 UI dump 轮询，必要时使用本地 ML Kit 中文 OCR。
- 两种模式共用页面分类、成功状态校验、金额/时间/商户等字段抽取及节流去重。覆盖微信、支付宝及多种购物 App 的部分页面；第三方页面改版或节点缺失可能漏报，具体规则以代码与样本为准。
- 识别后由用户确认保存，确认卡可修改金额、类型、分类、账户和备注。有悬浮窗权限时直接显示，受系统限制时退回 Activity 或待确认队列/通知；关闭“识别后自动弹确认卡”后只进入待确认队列。
- 本地账本支持手动新增、编辑、逐笔删除及短时撤销；统计区分支出、收入、转账和退款，结余按收入−原支出+退款计算。
- 分类与账户管理、备注模板、本地 JSON 规则、餐段设置、近 7 天识别计数与样本导出。学习仅在成功人工保存后发生；明确修改立即学习，接受相同推荐累计 3 次学习；关闭学习也暂停既有学习推荐。
- 月度概览/统计、待确认优先展示、浅深主题、字号与降低动效；四页浮动 dock，API 33+ 使用液体玻璃库，API 26–32 使用半透明兜底。桌面快捷方式、识别开关磁贴、本月支出 widget 已接入。
- iCost CSV 按官方 10 列模板导出；其模板不支持退款，范围内含退款时阻止导出并提示。另有 JSON 备份与合并/覆盖恢复。
- 内置可选 LSP 模块，以及无障碍异常巡检和权限引导。它们不能保证进程永不被杀或自动恢复服务，详见 [LSP 说明](docs/LSP_MODULE.md)。

所有账单处理与存储在本地完成；采集跳过可编辑输入节点，并设文本数量/长度上限。诊断样本、备份和导出可能包含个人交易信息，分享前应自行检查。

## 0.6.8 的变化与验证边界

品牌入口统一使用 **Auto.jpg**：桌面/主题图标、通知、磁贴、快捷方式、widget 与确认卡。保留四彩边框、白色内部，以及自适应 54dp/108dp、legacy 55% 的留白；单色图保留负空间。

微信新增严格的极简成功页规则，处理没有支付方式的“支付成功、收款方、唯一货币金额、完成”组合。无障碍窗口事件的 120ms 调度期限不再被后续内容事件推迟；纯内容事件最大等待 1 秒，根节点不可用仅重试一次。这些是调度参数，不是端到端弹框时延承诺。

已有证据为 221 项单测/24 类全绿、debug 与签名 release 构建成功及包内资源/版本/签名核查。当前 API35 模拟器目视仅覆盖新品牌的确认卡、QS 磁贴、已放置 widget；其他界面操作见旧版预览记录。**真实微信付款的瞬时成功页与悬浮确认链路仍待真机验证**，截图转录不能代替节点和事件日志。

## 构建与安装

需要 JDK 17、Android SDK 35；项目使用 Gradle 8.14、AGP 8.7、Kotlin 2.0.21，最低 Android API 26。

```bash
source "$HOME/opt/autobook-env.sh"
cd "$HOME/Projects/AutoBook"
./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

环境脚本适用于当前工作机；其他机器自行设置 JDK/SDK，并调整 `local.properties`。若 Gradle 缓存目录不可写，在加载环境后将 `GRADLE_USER_HOME` 设为可写目录。签名、正式打包与升级说明见 [部署指南](DEPLOYMENT.md)。已有候选包可直接覆盖安装：

```bash
source "$HOME/opt/autobook-env.sh"
adb install -r dist/AutoBook-0.6.8-release.apk
```

首次打开选择采集模式，再按首页引导授权并启用识别；无障碍模式需要系统无障碍服务，Root 模式需要设备已 Root 并授权 `su`。确认卡直弹需要悬浮窗权限，通知兜底需要相应通知权限。
