# 家庭账本备份与恢复

1.7.0 起支持。先在“设置 → 迁移与备份 → 家庭同步与备份”连接家庭服务并完成首次规则合并。

## 手动备份
点击“立即备份”，App 在私有目录生成同一账本事务视图的 JSON9（含只读删除记录），验证后上传家庭服务。成功后显示来源时间和账单数。上传失败保留原快照，下次点击重试同一份；成功后的下一次操作生成新快照。设备权限、采集设置、配对令牌与原始采集库不上传。规则仍走独立规则同步。

点击“查看家庭备份”读取来源设备、日期、数量和大小；“加载更多”继续分页。页面不会自动上传或删除备份。家庭服务目录与PG索引必须共同备份，部署及联合恢复见[家庭服务部署](../deploy/home-sync/README.md)。

## 下载并恢复
点击所选快照的“下载并预览恢复”，App 校验大小、SHA-256、JSON格式与条数后展示预览。选择合并或覆盖，再次确认才执行。

- 合并：按既有账单和资产身份去重，冲突时停止，不用时间强行覆盖。
- 覆盖：替换账单、资产与识别历史；请核对来源和日期。删除记录作为审计日志保留本机已有事件，再按事件编号合并备份里的记录；同一编号内容冲突会停止整个恢复。
- 默认保留本机规则、分类、周期、备注、设备权限和家庭连接。
- 可明确勾选恢复分类、周期和备注配置；备注修改经本地规则库产生新的待同步修改。个人识别规则和官方规则包不随账本JSON恢复；设备权限与配对信息始终保留。

两种方式都先把本机恢复前快照保存到App私有目录，保存失败不会执行恢复；保存与恢复共用主库事务，避免并发写入落在两者之间。恢复失败的数据库事务回滚，恢复点保留。通过“导出最近恢复前快照”将其保存到自行选择的位置；需要回退时可在本地“备份与恢复”页选择该文件恢复，请核对该页配置恢复说明。

恢复点和上传文件不会自动清理。卸载/清除App数据会失去私有文件，重要恢复点应导出到独立存储。家庭服务不可达不影响本地记账。当前仅支持手动备份；不做账单双向同步。

## 当前验证边界
已在API35隔离模拟器和本机PG17/文件卷验证，并完成独立目录联合恢复演练；不代表真实家庭HTTPS、真机恢复、API26或200MiB性能已通过。备份JSON未加密，家庭服务卷需按自己的数据备份管理。

## 删除记录兼容

JSON9 增加删除时间、原账单组快照及事件编号。删除记录仅供查看，不会作为活跃账单导入，也不会重新计入余额；恢复旧账本快照仍按用户明确选择的合并或覆盖执行，历史删除事件不作为自动删账指令。JSON1–8 仍可在 App 读取，旧文件未包含删除记录时保留本机已有日志。日志不随“清理已忽略记录”删除，也没有自动过期或恢复入口。

家庭服务需升级到同时支持 JSON8/9 的版本后接收新的 JSON9 快照；服务源码升级不会自动部署。旧服务拒绝新格式时备份失败并保留本机文件，不应当作上传成功。旧版 App 不理解 JSON9，需要升级后才能完整恢复。
