# 钱迹 XLSX 导入

入口：设置 → 导入导出 → 钱迹账单。同一菜单可进入 iCost 导出与完整备份恢复。

## 导入与核对步骤

1. 建议先在「备份与恢复」导出当前完整备份，再执行导入。导入不卸载、不清应用数据。
2. 选择钱迹原始 XLSX。核对预览，取消一次应不新增账单；再次选取可重新预览。
3. 预览会给出可导入、跳过、冲突三类计数。跳过项通常为报销记录、债务还款/借入、含优惠券的记录；账本列忽略，记账者等不保留字段另有计数提示。默认显示需关注记录，可切换筛选查看全部/可导入/重复，每次显示 50 条并可继续展开；点账单可查看来源行号和完整详情。
4. 确认追加后，核对首页、明细和统计。抽查支出/收入的金额、日期、分类、二级分类、备注和账户；打开转账详情核对转出/转入账户。导入不改变资产余额、不新增识别历史或学习。
5. 再次选择同一文件，已导入条目应为重复；同一钱迹 ID 内容改变时应为冲突且不覆盖。本机不存在的记录不会按金额和时间猜测去重，因此与自动记账或手工账单重合的同笔交易仍需人工核对。
6. 删除导入账单后，重新选文件仍会跳过；需要恢复这类记录可用含该账单的完整备份显式覆盖恢复。合并备份保留本机删除标记。JSON8 保存导入身份（格式 5 起支持），旧备份缺失身份时会提示跨旧备份的重复识别不完整。

## 当前支持范围

仅 CNY 支出、收入及双账户信息完整的转账。名称原样保留，唯一匹配现有账户或别名时才关联稳定账户身份；不创建分类/账户配置。报销、债务、未知类型、非 CNY，以及已报销、手续费、优惠券、关联账单非空的记录均明确跳过。其他未保留字段必须在预览核对后确认。

时间按预览所列本机时区解释；金额精确为分，不截断或浮点取整。单文件 10 MiB、展开总量 24 MiB、50000 条、64 列、单元格 16384 字符，累计导入身份 200000；拒绝公式、外部关联与异常文件。所有解析和写入本地完成。
